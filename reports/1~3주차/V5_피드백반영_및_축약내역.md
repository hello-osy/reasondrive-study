# V5 피드백 반영 및 축약 내역

동명 형 피드백에 맞춰 모호한 표현을 풀어 쓰고, 용어와 수치의 뜻을 보완했다. 최신 학습 결과를 추가하면서도 렌더링 기준 14쪽에서 12쪽으로 줄였다. 본문과 표의 글자 수는 13,218자에서 9,979자로 약 25% 줄었으며, 기존 이미지 20개와 주별 보고서 양식은 유지했다. V4 원본은 수정하지 않았다.

## 표현과 설명 보완

| V4에서 읽기 어려웠던 부분 | V5 반영 내용 |
|---|---|
| 기존 탐색 실험 | 팀의 초기 학습 실험으로 바꾸고, 당시 기록과 이번 실행 결과를 구분 |
| 수정 코드 자체 재현 | 장면을 분리한 수정본의 학습·평가 등 실제 작업을 구체적으로 설명 |
| train 4,192 / validation 517 / test 571 | 질문·정답 쌍(QA)의 개수이며 각각 학습·모델 선택용 검증·최종 평가에 쓰인다고 설명 |
| DriveBench | 이미지 조건을 바꿔 자율주행 VLM의 판단 성능과 시각 정보 활용을 평가하는 벤치마크라고 정의 |
| 서로 다른 숫자와 지표 | 프레임·이미지·QA를 구분하고 StrictEM, Accuracy, 유효 응답, %p, 신뢰구간의 뜻을 보완 |

## 줄이거나 뺀 내용

| 항목 | 처리와 이유 |
|---|---|
| 주별 요약·결론의 반복, 여러 곳의 TBD | 완료한 일과 다음 작업을 한 번씩 정리 |
| GPT-4o 생성 비용의 세부 예상표 | 대상 수·토큰 수·적용 단가 등 산출 조건이 충분하지 않아 삭제. 시범 생성의 사용량을 측정한 뒤 추정한다는 설명으로 대체 |
| 생성 결과의 JSON 필드 목록표 | 질문·정답·추론·이미지 경로를 저장한다는 문장으로 축약 |
| 테스트 개수, 가중치 텐서 개수 등 구현 세부값 | 어떤 오류를 확인하고 고쳤는지 중심으로 정리 |
| 답 추출 규칙 변경의 보조 집계 | 대상 선정과 집계 조건을 설명하기 어려운 세부 수치는 빼고, 오류와 수정 내용을 유지 |
| 보기 제거 표의 형식 준수율 열 | 분모와 판정 기준을 확인할 자료가 충분하지 않아 수치를 제외. 보기 유무에 따른 지각·행동 정확도는 유지 |
| 기존 실행 설정 | 완료된 실험의 실제 설정으로 교체. 모델별 학습량, 배치 변경, 검증·저장 주기는 유지 |

비용표와 형식 준수율은 산출 조건을 확인한 뒤 필요하면 복원할 수 있다. 나머지 세부 구현 정보는 주별 보고서보다 코드 설명이나 실험 부록에 두는 편이 읽기 쉽다.

## 최신 결과를 반영한 범위

- 10월 27일 23:01에 완료된 **공개 코드 기반 Simple·Reason 실험**의 설정과 결과표를 3주차에 추가했다. 회의 시간 이후이므로 ‘후속 실행’으로 표시했다.
- **장면을 분리한 수정본의 학습·평가는 미완료**임을 명시했다. DriveBench에서 평가한 공개 배포 모델과 팀이 이번에 직접 학습한 모델도 구분했다.
- 평가 528문항 중 학습과 겹치는 485문항, 두 모델의 서로 다른 Accuracy 채점 대상 수를 함께 적었다. 이 결과만으로 추론 학습의 효과를 결론 내리지 않았다.
- 초기 분할 4,192/517/571과 StrictEM 35.90%/33.10%는 V4의 당시 기록을 유지한 값이다. 이번 완료 실험의 값과 섞지 않았다. 제출 전 초기 원기록과 한 번 더 대조하면 좋다.

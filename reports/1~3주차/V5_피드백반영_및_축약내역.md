# V5 피드백 반영 및 축약 내역

v4를 원본으로 사용해 문장과 설명을 다듬었다. 기존 미완성 v5의 구성으로 대체하지 않았으며, v4 파일은 변경하지 않았다. 새로 진행한 공개 코드 기반·수정본 실험의 결과값은 요청에 따라 모두 TBD로 두었다.

## 유지한 내용

- 활동 주제: 추론 학습을 통한 자율주행 VLM의 판단 성능 개선 검증
- 1주차 논문·코드 분석 → 2주차 사전 검토 → 3주차 과제별 수행 결과의 흐름
- 오상영의 코드 보완, 남궁길의 추론 데이터 생성, 정동명의 DriveBench 평가라는 역할 분담
- 주별 활동 일시, 참가자, 활동 사진과 입력 이미지 20개
- 맑은 고딕, 본문 11pt, 섹션 제목 13pt, Word 기본 글머리표, 표 내부 가운데 정렬과 `<표 N. 제목>` 형식
- 논문 Accuracy, 초기 학습 실험의 StrictEM, DriveBench 객관식 정확도·baseline·신뢰구간·보기 제거 결과
- 코딩/오픈소스 SW 활동과 건의 사항 및 비고에 세 담당자의 작업을 함께 정리한 구성

| 수정 대상 | 반영 내용 |

| 고정 조건의 자체 재현 결과 | 반복 문장을 없애고, 공개 코드 기반과 수정본의 결과표를 별도로 배치 |
| train 4,192 / validation 517 / test 571 | 질문·정답 쌍(QA)의 수이며 학습·모델 선택용 검증·최종 평가에 각각 쓰인다고 설명 |
| 800프레임과 5,280 QA | 프레임은 같은 시점의 6방향 이미지, QA는 질문·정답 쌍이라고 설명 |

## 줄인 내용과 이유

| 항목 | 처리 | 이유 |
|---|---|---|
| 반복되는 요약·계획·TBD 문장 | 요약은 진행 상황, 본문은 수행 내용, 결론은 다음 작업으로 역할 구분. 새 결과표에만 TBD 표기 | 같은 내용을 여러 차례 읽지 않도록 정리 |
| GPT-4o 비용 추정표 | 비용 검토 방법을 한 문단으로 축약 | 생성 대상 수·사용량·적용 단가를 함께 확인해야 하는 예상값이므로 주별 보고서에서는 요청 방식 검토 내용만 유지 |
| JSON 저장 필드 표 | 질문·정답·추론·이미지 경로와 장면 ID를 보존한다는 문장으로 축약 | 과제 진행 상황보다 구현 상세에 해당 |
| 테스트 수·LoRA tensor 수 | 실제로 확인한 오류와 수정 내용을 중심으로 서술 | 검사 개수보다 작업 내용이 전달되도록 정리 |
| 학습 설정 | 수정본의 기본 설정 표는 유지하되 backend별 옵션과 일부 세부 하이퍼파라미터 축약 | 기본 설정과 실제 GPU 실행 설정을 혼동하지 않도록 구분 |
| 생성 예시의 영문 질문·긴 설명 | 한국어로 요약하고 원문 정답 유지 | 이미지와 추론의 관계를 바로 이해하도록 정리 |
| 출력 형식 준수율과 정규식 보조 집계 | 본문에서는 제외하고 아래에 원래 수치 보존 | 판정 기준 설명이 추가로 필요한 보조 분석이므로 핵심 정확도·이미지 조건 비교에 집중 |

축약한 표와 보조 집계는 아래 기록을 검토한 뒤 필요하면 복원할 수 있다.

- 비용 추정표: 질문별 고화질 일반/Batch 약 $460/$240, 질문별 저화질 $90/$55, 프레임별 고화질 $100/$60, 프레임별 저화질 $50/$30. **v4에 기재된 추정값이며 실제 지출액이나 현재 API 단가가 아니다.**
- 정상 입력의 answer 형식 준수율: Base 66.64%, Simple 99.91%, Reason 97.95%.
- 검은 이미지의 부재를 언급한 Reason 응답: 1,124건 중 3건.
- 속도 설명과 선택이 일치한 응답: 141건 중 77건.

## 새 실험 결과표

- 공개 코드 기반과 수정본을 구분해 Simple·Reason 표를 각각 추가했다.
- Accuracy, Accuracy 평가 문항 수, Final_noGPT, 유효 응답/전체 입력을 같은 형식으로 배치했다.
- 새 두 실험의 값은 모두 TBD이다. 미완성 v5에 있던 일부 공개 코드 실험 수치는 이번 문서에 옮기지 않았다.
- 수정본 설정 표는 기본 설정을 설명한다. GPU에서 변경한 batch, 학습 재개 등 실제 실행 조건은 결과를 추가할 때 함께 확인한다.
- 학습·평가 문항과 생성 조건이 다른 두 실험의 점수 차이를 코드 수정만의 효과로 해석하지 않도록 설명했다.
